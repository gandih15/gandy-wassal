# غاندي وصّل · Gandy Wassal

تطبيق أندرويد Offline بيخلّي صاحب المحل يبعت عروضه وإعلاناته لعملائه على واتساب، بصورة أو من غير صورة، وبأعداد كبيرة. مفيش سيرفر: كل الداتا على الموبايل.

## الفكرة
- **الصفحات:** كل حساب بيعمل صفحات، مثلًا "لمسة للإكسسوارات" و"كابتن صالون". كل صفحة ليها اسم ولون وتوقيع بيتحط في آخر الرسالة.
- **المنشورات:** جوه كل صفحة منشورات جاهزة (عرض أو إعلان أو تهنئة) بنص وصورة، و`{الاسم}` بيتغير لاسم كل عميل.
- **العملاء:** يدوي، أو من جهات الاتصال، أو من ملف CSV بصيغة `الاسم,الرقم,المجموعة`، مع مجموعات وإمكانية وقف الإرسال لأي عميل.
- **الحملة:** صفحة، وبعدين منشور، وبعدين المجموعات، وبعدين الطريقة، وتبدأ.
- **طريقتين للإرسال:**
  - **نص أوتوماتيك (آمن):** واتساب يفتح والرسالة جاهزة، يدوس إرسال ويرجع، والتطبيق يفتح اللي بعده.
  - **أوتوماتيك كامل:** خدمة الوصول بتدوس إرسال لوحدها، مع تأخير عشوائي وحد يومي، وبتكمّل تاني يوم.

## بناء الـ APK
كل Push على الـ Repository بيشغّل **Actions، وبعدين Build APK**. لما يخلص، افتح الـ Run وحمّل **GandyWassal-apk**.

### مهم قبل التوزيع: سر التفعيل
1. في الـ Repository افتح **Settings، وبعدين Secrets and variables، وبعدين Actions، وبعدين New repository secret**.
2. الاسم `WASSAL_SECRET` والقيمة أي كلمة سر طويلة تختارها انت.
3. اعمل **Re-run** للـ Build.

لو منعملتش الخطوة دي، التطبيق هيتبني بسر تجريبي معروف.

### توليد كود التفعيل لعميل
```
python tools/keygen.py كود-الجهاز
```
هيسألك على السر، فحط نفس قيمة `WASSAL_SECRET`.

## تفعيل الأوتوماتيك الكامل على الموبايل
1. الإعدادات، وبعدين الوصول (Accessibility)، وبعدين "غاندي وصّل – الإرسال التلقائي"، وفعّلها.
2. لو أندرويد 13 أو أحدث وقالك إنه "إعداد مقيّد": افتح معلومات التطبيق، وبعدين النقط التلاتة، واختار **السماح بالإعدادات المقيّدة**.
3. سيب الشاشة مفتوحة وهو بيبعت.

## تنبيهات
- الأوتوماتيك الكامل مخالف لشروط واتساب، والرقم ممكن يتحظر. استخدم رقم بيزنس منفصل، وابعت لعملاء المحل بس.
- لو واتساب غيّر زرار الإرسال في تحديث جديد، عدّل `findSendButton` في `WaAutoService.kt`.
- قبل النشر: اعمل keystore خاص بيك بدل مفتاح الـ debug.
